Pasal Wireframes

Nepal ko sano pasal (kirana) ko lagi inventory, bikri, udharo khata ra bill print app. Android ra iPhone dubai ma, offline ra online dubai ma chalne. Yo pahilo draft ho: rang, logo, naam pachi. Sample data kirana pasal ko rakhiyeko chha.

Screen flow

Login→2FA code→Home→Naya bikri→Payment→Bill print
Register→Pasal ko vivaran→Home | Saman→Stock kam→Order | Udharo khata→Grahak ko hisab

A. Suru: login ra pasal register

B. Dainik kam: home ra bikri

C. Saman, stock ra order

D. Udharo khata ra hisab

Prabidhi sujhab (pachi nirnaya garne)

App ra database
  • Ek code le Android ra iPhone dubai: Flutter (ya React Native).
  • Phone ma local database (SQLite), jun le offline ma kam garchha.
  • Online bhayepachi server (PostgreSQL) sanga sync.
  • Backend: API + login + sync. Nepal ko lagi Nepali miti (BS) ra Rs format.
Security
  • Password + 2FA (SMS OTP / authenticator), biometric.
  • Data encrypted (phone ra server dubai), HTTPS matra.
  • Malik ra staff ko alag pahunch; kun ले ke gareko log.
  • Card/QR ko paisa seedha eSewa/Khalti/FonePay/bank jastai provider bata; app le card number rakhdaina.
  • Din-din backup.

Agla kadam: yo wireframe ma ke badlane, ke thapne bhana. Tyas pachi app ko naam, logo ra rang, ani build suru.
